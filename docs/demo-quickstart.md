# Norma Demo：先跑通一条完整流程

## 当前机器直接使用

打开 http://127.0.0.1:8767/ ，进入 Demo 页。不要同时在多个页面创建视频会话；两个3090工作进程各承载一个场景。

1. 导入 `E:\Norma\.norma\workflow-demo-104`（104张开发演示照片），或自己的照片文件夹。
2. 点击“美学评估 · 相似只留最佳”，等待进度完成。已有OpenCLIP与MUSIQ足够支撑演示，不额外堆叠评分模型。美学保留阶段现同时使用哈希近重复、OpenCLIP高相似画面及裁切/变焦空间验证，优先显示综合高分代表；低于门槛或相近构图的照片折叠，**不删除原图**。可点“查看折叠”查看具体替代原因。相近构图判定仍可能误判，详细阈值和实测边界见 [本次修复说明](fix-visual-curation-20261006.md)。
3. 输入“挑4张雪山照片”或“挑一组适合发旅游朋友圈的照片”，点击“模型选片”。默认本地预训练图文检索，未指定数量时最多9张；不是任意复杂要求都能可靠执行。
4. 默认“助手审美（允许代理记录）”按授权使用已有代理案例，也可切换不使用偏好。它是冻结向量的案例记忆，不是训练或DPO。若没有相关案例，保留原排序。
5. 勾选两张照片，同意发送到自己的3090服务器，再点击“生成两张交互视频”。新会话初始化需要等待，本次两张分别约183秒和189秒，不能把等待初始化误认为实时响应；时长也不是固定保证。
6. 点击要操作的视频卡片。画面左下为WASD、右下为方向键，支持点按和物理键盘；W/S前后、A/D左右移动，方向键转动视角。生成中点亮已提交方向并禁用重复提交；播放/拖动进度时按真实动作历史点亮。每次只支持一个方向，不支持组合按键。点击画面右上“全屏”可连同按键一起放大。两张照片各自保存场景状态。
7. 累计7步的预览约10.31秒；当前第二工作进程最多14步，约20.81秒，以卡片显示为准。达到上限后新建会话，不能无限延伸。可回看历史、下载视频。

雪山与天坛的已有长片也可在 http://127.0.0.1:8767/world-demo/ 查看；这是历史输出展示，不等于该页在实时生成。

## 主流程与暂缓事项

照片 → 已有MUSIQ评估/近重复筛选 → OpenCLIP图文检索 + 数量/多样性约束 + 可选助手案例记忆 → 两张照片 → LingBot-World-v2非实时动作条件生成。

“文字大模型解析”是默认关闭的实验项；基础演示无需勾选。复杂条件理解尚不稳定，不声称已支持任意自然语言推理。暂缓新增评分类模型、后训练和独立收益评测，先保证导入、选片、探索和下载可用。

2026-10-06：已修复“挑出最适合这趟旅游展示的9张照片”被模型虚构条件拦截的问题，开启文字模型也已在trip真实相册验证返回9张，原文安全校验未关闭。刷新后勾选可选文字解析即可重试。具体证据与边界见[本次修复](fix-trip-selection-20261006.md)，不表示任意复杂要求全部支持。

生成的遮挡区域与新视角由模型推测，不是真实场景重建；视频可能漂移、变形，当前不保证回环一致性。上游许可边界仍适用。

## 关闭后如何恢复

在 `E:\Norma` 中运行（已有服务时不要重复启动）：

```powershell
python scripts/start_demo.py
```

另开一个终端保持已配置SSH连接，供视频工作进程转发；不会在这里记录密码或令牌：

```powershell
ssh -N -o ExitOnForwardFailure=yes -o ServerAliveInterval=30 -L 8769:127.0.0.1:8769 -L 8770:127.0.0.1:8770 USER@HOST
```

远端两个工作进程必须已运行。`python scripts/demo_doctor.py` 可做只读检查；连通性通过不等于模型推理通过。模型、图片、数据库和生成文件均保留在私有`.norma/`中，不提交到Git。
