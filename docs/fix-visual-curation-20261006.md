# 美学保留阶段的相近构图折叠

## 为什么用户仍看到很多近似雪山

用户截图是“美学保留104/160”，不是文字选片后的集合。此前只在后续选片求解器里加入OpenCLIP成对约束；美学筛选还依赖pHash/dHash分组，因此“相似只留最佳”在用户正在查看的阶段并没有兑现。这是链路遗漏，不能用后续阶段能去重解释成已经解决。

## 修复

在质量/美学门槛、哈希组保留代表图之后，按已有MUSIQ美学与技术质量综合分从高到低遍历：

- 读取与原图SHA、模型身份一致的缓存OpenCLIP图像向量，不重新训练、不新增审美模型。
- 余弦≥0.97：作为高相似画面候选折叠到已保留的高分图。
- 0.90≤余弦<0.97：增加SIFT局部特征、单应性RANSAC和灰度对齐验证，处理裁切、变焦导致全局特征下降的情况。
- 空间验证要求至少12内点、内点比例≥0.60、双向画面覆盖≥0.35、内点空间分布面积≥0.08、对齐后的相关系数≥0.75。0.35覆盖大致容纳1.7倍裁切变化；这属于相近构图筛选而非逐像素重复检测。
- 始终与仍被保留的代表图直接比较，不做传递性连通合并。高相似度与这些空间门槛仍是开发启发式，不是重复概率，不保证所有复杂场景都正确。

局部特征与空间验证缓存绑定原文件路径、内容SHA、大小、修改时间。curation摘要包含模型身份、向量摘要、算法版本、门槛和折叠映射；旧筛选自动失效，不冒充最新结果。网页显示额外折叠数量，并在“查看折叠”中解释具体保留了哪个文件。只改变显示与候选集合，不删除照片。

新版草稿沿用天坛/雪山必留和原人物提示。浏览器已有的手动必留或A/B指定不会被草稿刷新静默删除；如果其照片现被折叠，提示用户核对，不偷偷改变人物代表照。

学习模型提供图像表征和美学排序；几何检查补充空间一致性证据，不是用规则替代美学模型。贪心保留的收益是解释清楚、质量优先、不发生传递误合并；代价是依赖阈值、排序和表示能力，人物表情等细节可能不被全局相似度充分保留。原图与折叠原因必须可查看，人工指定与自动判断的来源不能混淆。

## 一段话总结

这次从用户指出“美学保留里仍有近似雪山”的反例定位到去重只作用于下游选片的链路遗漏，将冻结OpenCLIP图片特征和对裁切/变焦的几何验证前移到美学筛选，在相同评分下以质量优先、非传递的方式折叠相近构图，使本相册保留数从104变为37，指出的六张雪山近景留一张而环境远景仍保留，并记录每张折叠到哪张代表图；所有原图不变，结果仅作为当前开发样例验证，不夸大为通用重复检测精度。
