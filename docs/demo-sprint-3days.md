## 范围冻结

最新时长确认：用户不要求实时，指定雪山与建筑两张照片各>=10秒，允许生成等待。目前两条10.3125秒离线演示已实测交付，见 [双图记录](benchmarks/user-world-demo-20261005.md)；非实时自由控制会话仍未完成，不能以两条成片替代该项验收。

**最新需求覆盖（2026-10-05）：** 用户要“输入图片后自由探索，类似LingBot World”，不是固定图生视频。当前剩余时间主线调整为首图 → 有状态世界会话 → WASD/观察控制 → 连续生成画面，细节与验收见 [Enter Photo](enter-photo.md)。以下单镜头计划与操作记录保留为已做工作的历史；原有MP4成功不代表探索成功。模型/依赖准备已启动，交互功能尚未交付。

演示：公开/授权相册 → 按钮触发学习型质量与美学 → 自然语言选片 → 偏好调整 → 确认一张图片上传 → 真实图生视频 → 网页播放与下载。

首版保留网页与Python，不做桌面端。复用现有相册、OpenCLIP、人物命名与CP-SAT。停止前端大改。先单镜头视频，约2秒的低分辨率预览验证后再提高到3–5秒；多镜头约15秒是扩展目标，不用照片动画冒充真实图生视频。

首版模型变更：为减少依赖和启动成本，先用同一pyiqa推理框架的MUSIQ-KonIQ（技术质量）与MUSIQ-AVA（通用美学），各自预训练权重、各自分数尺度。原计划Aesthetic Predictor V2.5/SigLIP作为后续比较，不宣称已经接入。偏好记忆不等于通用美学评分。

### 当前演示怎么打开

1. 独立服务已运行时，直接打开 <http://127.0.0.1:8767>，不用再启动第二个占用同端口的进程。原来的8765仍为旧的主相册服务。
2. 导入公开小相册 `E:\Norma\.norma\sprint-album`（8张，附出处）。如果服务刚重启，先在Library点“语义索引”加载检索模型；已存在的图片向量可复用。
3. 在AI Selection输入“选3张建筑”。模型解析实验开关先保持关闭；普通流程使用既有有界解析、学习型图文检索和CP-SAT，不是模型理解实验成功。
4. 展开“模型实验 · 美学评估 / 图生视频”，点“分析相册质量与美学”；已有完成分数会复用。两类学习分数分开展示，不冒充个人偏好。
5. 选一张图，检查居中裁剪预览和镜头描述，勾选这张图上传确认，再生成约2秒预览。进度百分比仅表示去噪步数，加载/编码/解码/导出显示阶段。
6. 新请求不会把旧视频当成新结果。历史任务仍能查看、刷新和取消；下载不改原照片。没有相关偏好证据时，打开记忆也不会凭空个性化。
