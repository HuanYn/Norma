# Norma：照片到交互探索的一页 Demo

## 使用顺序

打开本机 `http://127.0.0.1:8767/`，默认进入 Demo。粘贴照片文件夹路径，点“导入照片”；导入只建立索引与缩略图，不立即启动重模型。之后点“美学评估 · 相似只留最佳”，等候质量、相似组、语义索引和美学模型完成。进度是当前阶段的实际完成比例，不是估计剩余时间。

默认美学门槛5/10、技术质量门槛40/100，可修改后点“重新筛选（复用评分）”。被折叠的照片仍在原目录，可以查看折叠原因，没有删片。输入“挑4长雪山照片”会显式纠正为“挑4张雪山照片”；输入“挑一组适合发旅游朋友圈的照片”，未写数量时默认最多9张。

从模型结果勾选两张，明确同意发送到自有3090服务器后，点“生成两张交互视频”。每张是独立场景，不把两张照片拼接成一个场景。点击其中一张场景，W/A/S/D控制前进、左移、后退、右移；↑/←/↓/→控制向上、向左、向下、向右看。鼠标也能点击视频下方同布局按钮。生成期间方向按钮禁用，完成后继续下一步；输入文字时不响应控制键，长按不连续提交。

首版每场景最多7步，累计165帧、16fps、10.3125秒。首段短于10秒，需继续到第7步得到完整10秒版本。每步都能播放、下载。刷新网页恢复本浏览器会话；服务重启不能恢复GPU缓存，会提示中断。闲置10分钟释放资源。画面外内容由模型生成，不是真实3D重建，也不保证无限漫游或回环一致。

## 实际算法与职责

1. 相似分组仍是保守的pHash≤7且dHash≤9连接组，针对近重复，不等于“同一主题全归一组”。美学打分使用冻结的MUSIQ-AVA，技术质量使用冻结的MUSIQ-KonIQ。每组按 `0.65*(AVA-1)/9 + 0.35*clip(KonIQ/100,0,1)` 选择通过门槛且未被基础质量拒绝的最佳照片。
2. 自然语言默认真正调用多语言OpenCLIP文本编码器，与相册图像向量计算语义相似度，再融合MUSIQ：`0.72*cosine + 0.18*AVA_normalized + 0.10*technical_normalized`。数量采用有限语法解析，**默认没有调用生成式大语言模型**。接口把“规则解析数量”“预训练模型排序”分开记录，不能在面试时混称大模型推理。
3. 可选“文字大模型解析”复用已配置提供方。本机目前本地解析模型尚未稳定通过验证；开启后失败会停止，不偷换模型。云端模式必须确认发送本次文字，不发送整个相册图片。本次验收使用默认本地模型路径，未证明云端解析效果。
4. 约束优化只接收美学保留集合。缺分、源文件变化、相似组变化或拒片标记变化会使快照失效；不把旧评分当新结果、不为凑数重新加入折叠照片。每次选片记录原始文字、纠正文字、快照和模型来源。
5. “参考我的偏好”复用已有冻结表征案例记忆，默认关闭，代理标签默认不参与。不是DPO/SFT，也没有本轮训练新模型。偏好成对反馈入口仍在AI Selection工作区，不在这页重复实现。
6. LingBot v2 1.3B的同会话KV、相机、RNG及latent状态持续保留。两张照片分配到两个独立worker/GPU，网关记录session→worker映射，切换活动卡片不切换或重建其生成历史。模型令牌只在后端；远端loopback监听，通过SSH连接。

真实双视频完整浏览器验收已通过：旅游组选出的雪山/建筑各7步、165帧、10.3125秒，1倍速完整播放及下载SHA一致；W/左右方向键只影响活动卡片，刷新后保留两个会话。雪山初始化145.519秒，各步6.523/9.849/13.269/16.361/19.292/22.309/25.281秒；建筑初始化139.478秒，各步5.224/7.778/10.413/12.870/15.497/17.778/20.376秒。两场景后6步的已显示前缀最大像素差均为0。该值只说明历史画面未改写，不代表新画面无几何失真。每图一次轨迹，不能当总体质量成功率。测试结束仅关闭自己的两个会话、释放推理资源，服务保留可供用户使用。

## 面试可能追问

- “美学模型是你训练的吗？”不是。贡献是按需评估、来源哈希绑定、模型排序融合、约束选择与前后端状态闭环。
- “所有相似照片都能找出来？”不能。当前主要识别近重复；机位变化大或语义近似可能分开，后续需冻结数据后评估学习型相似分组。
- “为什么旅游推荐不一定都适合我的朋友圈？”当前是通用语义与美学排序，未标注个人照片与陌生公开人像的业务界限，也未验证个人喜好。示例返回公开人像只能证明语义选择，不表示这些就是用户本人或朋友。
- “使用DeepSeek了吗？”本次默认链路没有；大语言模型是显式可选解析层。OpenCLIP是多模态表征模型，但不应把它说成生成式LLM。
- “为什么两张照片用两个GPU？”当前每个worker只保留一个活动会话。双卡是状态隔离与并发，不是测得的分布式加速；单卡状态换入换出尚未实现。
- “能证明审美提升吗？”不能仅靠MUSIQ分数证明。独立人工留出偏好标签尚缺，需盲评、来源组隔离和组级置信区间。

## 启动与边界

本机入口用 `python scripts/start_demo.py`，静态页面构建为 `.norma/demo-web-dist`。两条SSH隧道连接本地8769/8770到服务器同端口；远端两个服务保留已有模型与独立数据目录。原来的 `/world-demo/` 为固定轨迹展示页，不冒充当前交互状态。
